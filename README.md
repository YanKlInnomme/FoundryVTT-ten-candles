# Système de jeu Ten Candles pour Foundry VTT

Ten Candles est un jeu de rôle d’horreur tragique à narration partagée. Les personnages affrontent leurs dernières heures dans un monde sans lumière, tandis que dix bougies rythment la partie et rendent sa conclusion inéluctable.

Ce système non officiel fournit à Foundry VTT les fiches, les cartes narratives et la table de rituel nécessaires pour accompagner une partie de *Ten Candles*. Il est développé pour Foundry VTT v14 et propose une interface en français et en anglais.

# Ten Candles Game System for Foundry VTT

Ten Candles is a tragic-horror, shared-narrative role-playing game. The characters face their final hours in a lightless world while ten real candles pace the story toward its inevitable conclusion.

This unofficial system provides Foundry VTT with the sheets, narrative cards, and ritual table needed to support a *Ten Candles* session. It targets Foundry VTT v14 and includes both English and French interfaces.

If you enjoy this system and are in a position to do so, you can support my work by buying me a coffee on Buy Me a Coffee (https://www.buymeacoffee.com/yank). Your support is greatly appreciated and helps fund the continued development of this project. Either way, I hope you enjoy using it. If you have any comments, suggestions, or questions, please don't hesitate to get in touch.
